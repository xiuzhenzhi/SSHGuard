# 用户与登录防护

## 用户与权限

管理员在“用户与权限”创建用户，选择管理员、操作员或只读用户。用户名去除首尾空白后须为 3–64 个字符；例如“测试”仅有两个字符，可改为“测试用户”。密码须为 12–72 个 UTF-8 字节，中文字与字符数并不等同。用户名重复会提示“用户名已存在”。

管理员可删除其他用户。确认删除后，该用户的所有登录会话立即失效，告警和操作审计保留，旧审计记录仍可查看操作者名称。不能删除当前登录账号；删除管理员时会校验剩余管理员，防止并发操作移除最后一个管理员。删除无法撤销，重新创建同名账号会产生新的用户身份。

## 手机访问

手机登录页直接显示登录表单；进入控制台后，点击左上角菜单按钮打开侧边栏。选择页面、点击遮罩或关闭按钮均可收起菜单。

登录时请等待验证码就绪后再提交。正在提交时不会重复发送登录请求；会话失效后需重新登录。

## 配置验证码

1. 打开「登录防护」，选择验证码服务。
2. 填写服务商密钥和允许访问的主机名。
3. 输入当前管理员密码并保存。
4. 保留当前会话，在另一个窗口测试登录。

| 服务 | 填写内容 |
|---|---|
| Cloudflare Turnstile | Site Key、Secret Key，action 为 `login` |
| Google reCAPTCHA v2 | 复选框网站的 Site Key、Secret Key |
| 极验第四代 | Captcha ID、Captcha Key |

主机名填写域名或 IP，不带协议、端口和路径。默认不启用验证码；禁用后 IP 封禁规则仍有效。

## 60 秒内错误 5 次，封禁 24 小时

按来源 IP 统计密码和验证码错误。第 5 次起封禁 24 小时；验证码服务故障不累计错误次数。

管理员可在页面解除封禁。共用 NAT 出口的用户会共用计数，SSH IP 白名单不影响此规则。

## 反代设置

反代需传递真实客户端 IP。跨机器或 Compose 部署时配置 `TRUSTED_PROXY_CIDRS`，见 [反代说明](../deployment/REVERSE-PROXY.md#审计来源-ip-与可信代理)。

验证码无法加载时，检查站点 CSP 和浏览器对第三方资源的拦截。

## 本机恢复

优先通过已有管理员会话修正设置。无法登录时，备份数据库并停服后处理：

- 关闭验证码：删除 `login_protection` 中 `id=1` 的记录。
- 解除指定 IP：清空 `login_guards` 对应记录的 `blocked_until`，并删除该 `source_hash` 的 `login_failures`。

只处理目标记录，不清空整张安全记录表。
