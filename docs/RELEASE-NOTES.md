# SSHGuard v0.3.24

- 新增 Windows RDP 与系统控制台登录采集，适配 TigerVNC、RealVNC、TightVNC、UltraVNC 日志，统一展示登录成功与失败记录。
- 控制台事件显示为“远程 VNC 登录”，不记录用户名；系统无法区分服务商 VNC / KVM 与本地控制台，未提供的来源 IP 不作推测。仅打开服务商远控窗口不等于操作系统登录。
- SQLite、PostgreSQL、MySQL 增加远程登录事件支持并保留历史 SSH 记录。主控先升级，再更新 Agent 至 v0.3.22；VNC 日志与 Windows 审计策略需按采集文档配置。
- Windows 采集改用原生事件日志 API，消除轮询子进程；复用文件读取缓冲区，减少 VNC 解析分配。默认 Go 内存软目标为 32 MiB，并尊重运维环境变量设置；该目标不是进程总内存硬上限。
- 修复 Unicode 日志导致 VNC 来源 IP 提取错位或越界，以及未认证连接被误判为成功的问题。
- 重做登录页与动画，简化移动端布局；移除桌面动画暂停按钮，补齐网站图标。弹窗仅通过关闭、取消、操作完成或 Esc 关闭，点击遮罩不再关闭。
- 本地模拟记录仅用于预览，不包含在发行包中。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
