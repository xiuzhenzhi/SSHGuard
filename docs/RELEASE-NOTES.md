# SSHGuard v0.3.23

- Agent 安装上报间隔支持 1–600 秒（最多 10 分钟），默认仍为 5 秒；前端、注册接口、心跳校验和 Agent 配置读取同步支持。
- 在线状态与离线告警按实际上报间隔计算宽限，使用上报间隔的三倍且最少 90 秒；600 秒间隔对应 30 分钟宽限。离线告警还遵循规则阈值，取两者中较大的值。
- 超过 30 秒的上报间隔使用 HTTP(S)，避免长时间空闲的 WebSocket 被反代关闭；采集和本地持久化队列继续运行。
- 统一列表、总览与告警的时间边界；拒绝保存超范围的 Agent 注册配置，并保留原配置。
- 补充 600 秒注册及上报、601 秒拒绝、离线临界值和 SQLite / PostgreSQL / MySQL 集成验证。
- 主控和 Agent 均需升级到此版本才能使用新增间隔范围。更新保留已有间隔；要改变间隔，在安装命令中选择后重新执行注册安装，重新注册会重置本地待传队列和采集位置，请先等待待传事件上传完成。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
