# SSHGuard Agent v0.4.1

## 更新内容

- 支持 Windows RDP 会话重连成功记录，采集用户名、时间及可用的来源 IP。
- 优化本地持久队列：缓存附加日志源游标，跳过无变化写入，减少上传批次读取时的内存分配。
- 保留事件与游标原子提交、离线持久化、确认后删除及重启恢复机制。
- 更新跨平台构建大小、运行占用和数据库页复用的验证记录。

提供 Linux / Windows 的 amd64、arm64 程序及 SHA-256 校验文件。

已有安装请使用更新命令，保留配置和待传队列。新增 RDP 重连日志源从首次启动时的末尾开始采集，不补报历史记录。

# SSHGuard v0.4.0

- 优化大数据量概览查询：增加覆盖索引，分离统计缓存锁，减少趋势查询对其他概览请求的阻塞。
- 创建用户补充用户名与密码校验、重复用户名提示；密码按 UTF-8 字节数校验，三种角色均支持创建。
- 新增管理员删除用户：撤销该用户全部会话，保留告警和审计历史及操作者名称，禁止删除当前登录账号，防止并发删除最后一个管理员。
- 新增“Agent 上线”检测规则，首次上线或离线后重新上线触发，支持分组、渠道和冷却时间；默认停用，正常心跳不重复告警。
- 告警详情新增服务器当前公网 IPv4 / IPv6，独立于登录来源 IP；补齐告警与操作审计中文，修复切换上线规则时隐藏字段导致保存失败的问题。
- 主控、Agent 与文档本次均为 v0.4.0，此后独立递增，不互相跟号。升级 Go 至 1.26.11，修复标准库 net/http 安全问题 GO-2026-6859；主控和 Agent 均重新构建，建议先更新主控，再更新 Agent。
- 主控 Release 精简为两个架构安装包、统一安装脚本和 SHA256SUMS，共四个下载文件；Agent 在独立 Release 发布，管理脚本保留在安装包内。
- SQLite、PostgreSQL、MySQL 增加统计索引、默认上线规则和已删除用户审计名称快照表。首次启动会执行迁移，事件量较大时创建索引可能延长启动时间并增加磁盘占用。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
