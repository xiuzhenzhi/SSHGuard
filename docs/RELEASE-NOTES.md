# SSHGuard v0.3.22

- 反代支持自动识别访问域名、协议和端口，无需重复填写 `PUBLIC_URL`；显式配置仍优先。默认信任同机反代，跨机器或容器反代需配置准确的可信代理范围。
- 修复 HTTPS 反代下初始化、登录和 WebSocket 的来源校验，登录 Cookie 与 Agent 安装命令跟随外部访问地址；关闭 HTTP 时拒绝自动模式下的明文初始化和登录。
- 安装脚本按 Komari 的方式读取 `hostname -I` 首个地址，输出实际监听地址，明确仅监听本机的端口不能通过机器 IP 直连；更新保留已有监听配置。
- 修复非托管反代模式下 IPv6 固定地址阻止更新的问题，本机健康检查不再受系统代理影响。
- 补充自动地址与固定地址两种真实 HTTPS 反代验证，以及直连、来源校验和安装脚本回归测试。Agent 保持 v0.3.20，无需升级。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
