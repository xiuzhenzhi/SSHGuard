# SSHGuard v0.3.26

- 修复登录后偶发自动退出：实时连接检查不再将数据库暂时不可用或 WebSocket 心跳失败误判为会话过期，连接故障改为重连。
- 前端收到实时连接的会话失效信号后，重新检查登录接口；仅确认 HTTP 401 时退出，暂时性网络或服务异常保留登录状态。
- 保留 12 小时会话有效期及撤销校验，增加有效会话、心跳失败、查询取消、数据库故障、过期与撤销的回归测试。Agent 保持 v0.3.22，无需升级。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
