# SSHGuard v0.3.25

- 服务器管理新增当前页勾选、全选，以及批量更新 Agent、修改分组、撤销凭证、删除服务器。执行前确认目标，完成后逐台显示结果；操作权限与审计沿用现有规则。
- 新增独立分组更新接口，只修改分组，不覆盖名称或备注；支持留空清除分组。
- 每页条数支持 10、20、50、100 条，并随地址保留。切换分页、筛选或条数会清空勾选，同页数据刷新保留勾选。
- 批量操作遇到权限失效或连接异常时停止后续请求；无法确认的执行结果单独提示，避免误报为失败或自动重试。
- 精简批量操作工具栏和每页条数下拉菜单留白。Agent 保持 v0.3.22，无需升级。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
