# SSHGuard v0.4.1

- 主控自动检查独立 Agent 正式发布版本，修复 Agent 单独升级后仍显示“已是当前版本”的问题；安装链接、更新命令及平台更新统一使用检测结果。
- 版本检查在后台执行并缓存，网络不可用时保留已知版本；更新任务固定目标版本，避免新版本发布或主控重启导致任务失效，并阻止降级更新。
- 配套 Agent 保持已发布的 v0.4.1，包含 RDP 会话重连采集与本地持久队列优化，本次不重复发布 Agent。

升级前备份数据库、配置和 ENCRYPTION_KEY。数据库类型不会自动切换或搬迁，程序回退不撤销数据库迁移。安装与升级见 [快速开始](guides/QUICKSTART.md)。
